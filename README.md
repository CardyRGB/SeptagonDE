### SeptagonDE by z4inn
- A desktop environment for Arch Linux combining MangoWC and the Noctalia desktop shell.
- The only dependency for installation of this is **yay.**
- It works on any Arch distro!
## Features
- 4 built-in 4K stock wallpapers (Septagrounds)
- Down to ~810MB RAM on idle
- From an Arch minimal installation, Septagon only takes less than 5GB of storage space!
