Septagon is a desktop environment for Arch Linux that uses MangoWC and Noctalia's shell. It uses a custom-made, organised Mango configuration tinkered and carved specifically for Linux users of intermediate skill. It provides almost unattended installation and a tutorial configuration. Installing it involves just one dependency, which is Yay. Installing yay on different distros use different processes, for example, EndeavourOS has yay preinstalled, CachyOS has it in its custom pacman repos, and on stock Arch you have to compile it. To install it, you may run these commands:
git clone https://github.com/CardyRGB/SeptagonDE.git
cd SeptagonDE
./install.sh (or if in a different shell, bash ./install.sh)
Then, cooperate with the instructions. It is reccomended to log out after installation to log into the Mango session, which is the Septagon session.
